# StockPilot

StockPilot is an open-source pipeline that takes a distribution company's raw data all the way to
replenishment decisions: it audits data quality, forecasts demand with uncertainty, sets safety
stock and reorder points, simulates the outcome in Thai baht, exposes everything to AI agents
through an MCP server, and publishes a static dashboard.

> **All data in this project is synthetic.** It is generated by `stockpilot.synth` for a
> fictional Thai distributor. No real company's data, names or figures are used or referenced;
> any resemblance of generated names to real businesses is coincidental.

## Pipeline

```
stockpilot.synth            synthetic ERP exports (data/raw) + ground truth (data/truth)
   │
   ▼
data quality audit          detect and repair problems, scored against the truth      (Step 2)
   │
   ▼
forecasting tournament      probabilistic demand forecasts per SKU × warehouse         (Step 3)
   │
   ▼
inventory optimisation      safety stock, reorder points, simulation in THB            (Step 4)
   │
   ├──► MCP server          AI agents query the system                                 (Step 5)
   └──► static dashboard    GitHub Pages                                               (Step 6)
```

## The synthetic dataset

<!-- generated:readme-summary:start -->
The default synthetic dataset (seed 42) covers 2021-01-01 to 2025-12-31: 2,000 SKUs, 600 customers, 60 suppliers and 3 warehouses, with 4,022,207 raw sales rows and 341,666 purchase-order items. Details and limitations: [docs/DATA.md](docs/DATA.md).
<!-- generated:readme-summary:end -->

The data mimics ERP exports of a Thai distributor — SAP-style material codes, box/piece units,
Thai public holidays, promotions, product launches and discontinuations, a lost key account,
supplier delays and stockouts that censor sales — and contains deliberate data-quality problems
(stripped leading zeros, duplicate rows, unit mismatches, extra-zero typos, Buddhist-era dates,
Thai/English duplicate customers, missing prices). Every problem and the true, uncensored demand
are recorded separately as ground truth for scoring later steps.

## Quickstart

Requirements: Python 3.11+, [uv](https://docs.astral.sh/uv/) and GNU make. Everything runs
offline once dependencies are installed.

```bash
make install    # create .venv from uv.lock
make data       # generate and validate the synthetic dataset in data/
make test       # run the test suite
make lint       # ruff lint + format check
make help       # list all targets
```
